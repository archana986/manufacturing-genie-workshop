Optional optimizer

Auto-Optimize is optional and stays on staging.

Default: human PR

A thumbs-down or a failed benchmark becomes a pull request. CI validates. A person promotes.

Optional: Auto-Optimize

Clone, train / validation / holdout. Keep a change only if the score improves. Roll back if it drops. Needs Prompt Registry (workspace Preview, Beta).

MaxGenie is archived. Use Genie Workbench. Do not install a second optimizer. Skip Auto-Optimize if Prompt Registry is off.

Close the lab

Fork the bundle, configure targets, and promote deliberately.

  1. Copy level-3-production/ as the project root.
  2. Set catalog, schema, warehouse, parent path, and workshop root.
  3. Replace placeholder catalog.schema in the Genie export.
  4. Run bundle validate --strict.
  5. Deploy gold, then metric views, then Genie, then the app.
You leave with a forkable bundle and a human promotion path. Staging and prod stay a person.
